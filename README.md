## 🤖 Machine Learning Projects

Built after completing Andrew Ng's **Machine Learning Specialization**. Each project implements the core algorithms from scratch with NumPy first, then compares them with standard libraries.

1. *[House Price Prediction](./House%20Price%20Prediction)*
   * *Description:* Linear regression built from scratch with gradient descent on the California Housing dataset, with feature scaling, a train/validation/test split and RMSE / R² evaluation.
   * *Topics:* linear regression, gradient descent, feature scaling, cost curves
   * *Next:* polynomial features, learning curves and Ridge/Lasso regularization.

2. *[Customer Churn Classifier](https://github.com/elshafie233/Data-Analysis-Portfolio/tree/main/Customer%20churn%20classifier)*
   * *Description:* Predicts which telecom customers will leave. Logistic regression from scratch, then decision trees, random forests and XGBoost, compared with proper evaluation.
   * *Topics:* logistic regression, regularization, overfitting, bias vs. variance, train/validation/test workflow, precision / recall / F1, class imbalance, decision trees, ensembles, error analysis

3. *Image Classifier with Neural Networks*
   * *Description:* Classifies handwritten digits and clothing images. A neural network written in NumPy (forward and backpropagation), then the same idea in TensorFlow/Keras.
   * *Topics:* neural networks, activation functions, softmax and multiclass classification, Adam optimizer, dropout, hyperparameter tuning, analysis of misclassified images

4. *Movie Recommender, Clustering & Reinforcement Learning*
   * *Description:* A recommender system on MovieLens, unsupervised analysis of users and movies, and a reinforcement learning agent.
   * *Topics:* collaborative filtering, content-based filtering, K-means, PCA, anomaly detection, Q-learning / Deep Q-Network
